# 导管工艺采集实施计划

**目标：** 保留现有零件采集契约，增加公式正文与输入输出引用、GSM 几何依赖、扫掠中心线及可追溯的导管弯曲几何表。

**架构：** `CaaEngineeringCapture::Extract` 隐藏原生接口、引用解析、采集失败和属性投影；`AnalyzeTubePath` 只接收毫米制实测曲线段，返回连接顺序、长度、弯角和相邻弯曲平面转角。仅对真实扫掠引用的中心线作分析，不按文件名、树标签或参数 D 判断导管。通过现有 PropertyFact 和 FeatureDependency 入库，不引入第二套持久化通道。

**约束：** C++03 / VS2008，兼容 intel_a 和 win_b64；新增及修改函数写中文注释；不更新或保存用户 CATPart；失败不填零；机床工序、回弹、夹持补偿不由几何推断为事实。

- [x] 建立无 CATIA 依赖的曲线链计算模块及测试：乱序、反向、平面/空间弯、断链、分叉、闭环、退化与非切向连接。
- [x] 建立 CAA 适配模块：读取公式 Body(0)、输入输出参数；真实扫掠中心线与截面；Join 元素；直线/圆弧控制点、支撑；实测曲线端点、中点、长度及圆弧半径。
- [x] 输出带来源、方向约定、状态的属性和语义，保持原有 resultout 计数口径。
- [x] 编译 x86，实测 M-D3232K01436-202；跑普通零件、装配体与既有铺层兼容测试，验证属性入库通道；记录 x64 未实编限制。
