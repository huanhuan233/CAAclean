# P3 基础消参识别验收记录（2026-10-04）

本轮 Feature Center 在一次 FreeCAD STEP 导入期间，为有限圆柱面计算材料侧、轴向裁剪范围、全周角向覆盖和沿轴两端的材料扫描证据；随后按 Solid 建图、归组并识别。无原生树和 `native_features` 时同样运行。规范 `CanonicalFeature`、`Observation`、`Measurement` 和 `feature_geometry_links` 沿原有 Bundle/数据库/API/Viewer 链路发布，不创建第二套识别结果。

## 当前可确认的几何类别

| 类别 | 确认条件与测量定义 | 验收 |
| --- | --- | --- |
| 普通贯穿/盲圆孔 | 内壁材料侧、有限轴向边界、36 方位覆盖、两端沿轴材料扫描；直径为解析圆柱 R×2，圆柱壁长度为真实边界投影 | 纯 STEP 合成件：通孔、平底盲孔、锥底盲孔、大直径浅孔通过；CATIA 导出孔样件解析出 7 个内壁组，未逐项人工对照 |
| 同轴阶梯孔 | 不同半径内壁同 Solid 同轴且实际端点相接、相接处空域连续；父孔包含分段列表，不把子段另计为 Canonical | 两段贯穿阶梯孔通过；有隔板的同轴双盲孔保持两个结果 |
| 普通直边定半径圆角 | 圆柱过渡面、两真实共享有限直边、两支撑平面到轴的距离等于解析 R、边方向与轴平行 | R3 合成件通过；凹凸仍是 `unknown`，圆环/一般曲面不确认 |
| 两平面直边与圆孔口锥面倒角 | 直边使用过渡平面、真实共享直边、支撑虚拟交线和法截面 D1/D2；圆孔口使用锥面与内孔壁、顶面两条真实共享圆边测轴向/径向距离 | 等距 4/4、不等距 3/6、孔口 2/2 合成件通过；制造意图仍 `not_evaluated` |

外圆柱凸台、无孔块不产生孔，半圆开放槽只产生待复核的圆柱空域候选；多 Solid 按各 Solid 单独输出；刚体变换件保持等价尺寸；米单位 STEP 与毫米件测得相同 10 mm 直径及 30 mm 长度。STEP 导入器会同时呈现 `App::Part` 聚合与叶级对象，解析入口已排除该重复定义。输出绑定 shape hash、规则版本和容差；Viewer 面范围通过原有一面一 Primitive 映射写出。原生 Hole 与几何结果仅在同一几何快照、更新状态有效且**孔壁面集完全一致**时合并到同一 Canonical，来源 Observation 及设计/B-Rep 值仍分别保留。

识别结果沿用 `canonical_features` 分页列表；新增 `GET /api/component-builds/{build_id}/viewer/recognized-features/{feature_center_id}` 从已发布的 PostgreSQL JSONB 记录按需返回单条特征、测量和面角色链接。页面保持约 400 px 详情面板，在选择后读取详情，不重新加载 GLB。新请求会使旧详情失效，失败时保留明确错误和重试入口。发布包的 shape hash 与面映射须一致；损坏资产不作为可信定位发布。

## 明确限制与未验收

- 普通圆角只确认解析圆柱加两平面支撑的直边过渡；圆环、管弯头、球面、变半径、多段复杂过渡尚未确认为圆角。
- 倒角只确认两平面直边与圆孔口解析锥面；非直角支撑的真实样件及楔形误判集尚未完成。几何形状不能证明 CATIA 历史或制造意图。
- 孔口完整环、半圆开放槽、交叉孔、长距离薄隔板和复杂分裂面的反例仍需补充独立样件；当前仅核对米与毫米两种等价单位。扫描达到上限的面保持候选，不应标记 confirmed。
- P2 原生圆角/倒角/草图新增字段需要**重新采集** CATPart；已有有效 STEP/B-Rep 快照只新增 P3 算法时可**仅补算识别**。旧包回填不会凭空生成原生设计参数。
- Docker `caaclean-postgres-live`（映射端口 55400）上执行了真实 PostgreSQL 发布、分页和按需详情事务测试，结果 `1 passed`。另经 API 上传纯 STEP 通孔件，构建状态 `ready`，列表返回 1 条识别孔，详情返回通孔、2 条测量及 1 个可信面引用。
- 在本地浏览器打开该构建的 Feature Center，点选识别通孔后右侧窄面板显示直径 10 mm、圆柱壁轴向长度 30 mm，中央 Viewer 仅高亮孔壁。原先纯 STEP 被重定向、且要求原生树入库的旧入口已修正。该浏览器冒烟只覆盖通孔；圆角、倒角、阶梯孔的逐项浏览器验收仍为 `not_run`。

P4 可复用同 Solid 图、单任务材料侧扫描、有限面证据、统一 Observation/Measurement、面角色链接、shape hash 一致发布。P4 型腔/筋条等类别没有在本轮启用。
