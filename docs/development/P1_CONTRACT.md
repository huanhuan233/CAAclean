# P1 公共几何与测量契约

## 引用与来源

请求以 `revision_id`、不可变 `geometry_snapshot_id`、几何资产 SHA-256、来源命名空间、零件定义、实例及体/面/边/点局部标识解析同一真实 B-Rep。内部索引只在所绑定快照中有效。显示 GLB 的 primitive、Three.js UUID 和原生 CAA ID 不是 B-Rep 标识；没有本快照可信映射时返回 `stale_reference` 或 `geometry_unavailable`。网格命中点只是位置种子，需投影并验证在裁剪面内。旧记录可查看，但没有几何快照时不能执行精确交互测量。

## 坐标、单位与容差

内部点为列向量，4×4 行主序矩阵左乘，长度统一为 mm；面积 mm²、体积 mm³、角度 deg。点包含平移，方向不含平移，法向使用逆转置并归一化。已有全局几何不再应用实例变换。拒绝奇异矩阵、反射、非均匀缩放和来源不明的实例变换。源单位变换只在 STEP/采集边界应用一次。计算公差以几何尺寸和内核容差选取并记录，角度公差、采样间距、显示弦差、小数显示位独立配置；内核公差不等于承诺测量误差。

## 操作与响应

统一操作为 `detail`、`distance`、`angle`、`section`、`local_thickness`。按需查询面/边类型、邻接、局部求值、裁剪区域、实体内外、射线求交。响应包含结果 ID、引用、操作及参数、单位/坐标系、值、测量点/截线、算法/内核版本、实际容差、来源和诊断。状态为 `success`、`empty`、`multiple`、`geometry_unavailable`、`stale_reference`、`unsupported`、`invalid_input`、`timeout`、`failed`；失败没有成功数值。

- `detail`：按真实类型返回点、有限边/弧、裁剪面和实体参数；大 NURBS 载荷按需请求。
- `distance`：有限拓扑之间的最短距离，返回两侧最近点、零距离交叠情况及多解状态。无限支撑几何投影不可替代裁剪结果。
- `angle`：必须指定线线、线面或面面定义及有向/无向约定；局部曲面需要有效求值点。没有材料侧时不声称内角。
- `section`：真实 B-Rep 与指定平面求交，返回闭合环、孔洞、开放截线、净面积及轮廓统计；显示离散化单独记录。
- `local_thickness`：指定面内点和实体材料侧，沿法线求当前连续材料区间。多个材料段分别返回，不跨空腔相加；多点结果称“采样最小厚度”。开放壳体无材料侧证据时 `unsupported`。

API 仅接受受控对象 ID 和参数，不接受客户端文件路径、脚本或表达式。计算在现有 FreeCAD 子进程中执行，超时终止进程；同一批请求只打开同一快照一次。缓存键包含快照、实例变换、操作、对象、参数、容差、算法与内核版本，限定内存和生命周期。`native_only` 未实现则返回 `unsupported`，不静默调用 FreeCAD。

交互结果保存在现有 `CadMeasurement` 通道，并以来源/算法版本区别自动事实、原生设计值和交互测量。整版本自动重算仅替换其自身算法版本。数据库查询失败不能回退 JSONL 冒充成功。

## 首批验收

以参数化合成件验证点/向量/法向、两实例、mm/m、非法变换、有限边/面最短距离、多解/相交、角度定义、带孔和多区域截面、连续材料局部厚度与空腔反例；以真实保存 STEP 验证一次导入/资产指纹/快照映射。前端验证 360/400/440px 窄面板、主对象身份、A/B 测量会话、旧请求隔离、标注清理和不可用状态。真实 CATIA/数据库/浏览器仅在实际运行后标记通过。
