# P4B 薄壁与结构角色验收（2026-10-04）

同一次 FreeCAD STEP 导入中先筛选同一 Solid 的相对裁剪平面，再以有限面投影及 Solid 与线段的精确求交，验证一个位置的连续材料区间。每项局部厚度保存两端点、方向、材料区间和计算方法。候选数与面数设上限；超限只记诊断，不中断几何浏览。

| 几何/角色 | 验证内容 | 当前状态 | 合成参考 |
| --- | --- | --- | --- |
| 直筋候选 | P4A 矩形凸台的相对侧面、有限顶边、根部支撑、局部连续材料厚度；与父几何特征建立关系 | 几何测量有效，工程功能 `candidate` | `straight_rib.stp`：长 50、厚 3、高 10 mm |
| 腹板候选 | 相对裁剪平面之间一个位置的连续材料区间及局部厚度 | 局部薄壁已核验，承载角色 `candidate` | `thin_plate.stp`：60×40×3 mm；厚块反例无结构输出 |
| 缘条候选 | 两个共顶面薄带、两侧自由边及与正交腹板的拓扑连接 | 几何带厚度/宽度可用，缘条角色 `candidate` | `tee_flange.stp`：宽 12、厚 3 mm，关联腹板厚 3 mm |

右侧沿现有窄详情面板显示局部厚度、位置、方向、长宽高、根部与连接面；几何测量可为 `valid`，结构角色仍为 `needs_review`。默认高亮仅限参与薄壁/缘条面，参考支撑面保持证据角色。结果沿现有 Bundle、数据库、详情 API 和 Viewer 资产发布，不另建体系。

局部厚度只代表**记录位置**，不是全局最小或名义厚度。交叉筋、渐变侧壁、筋根圆角、带孔腹板、多型腔公共隔筋及真实业务件尚未完成独立验收；这些功能角色不得升级为确认。浏览器逐项点选为 `not_run`。有效 STEP/B-Rep 可仅补算识别；新原生字段仍需重新采集。
