# P5 产品属性与 MBD 验收记录（2026-10-04）

## 已实现的链路

- R21 CAA 只读采集：`CATIPrdProperties` 的产品字段按 Reference/Instance 记来源；直接子级用户属性与 Part Knowledge 参数保留对象路径、类型、原值、单位和字段读取状态。实例与定义不合并。
- FT&A/TPS：标注集、原生视图/捕获、标注定义与成员关系使用独立 ID。通用 TPS 和文本接口不覆盖专用类别；多个专用接口冲突时标记 `multiple_tps_types` 并保存冲突字段。线性尺寸的极限值才标为 mm；角度及未分类尺寸保留原值、单位 `unknown`。公差带值/形态、复合值/段数、基准框文本由本机 R21 接口分别读取，字段失败不覆盖成功字段。TTRS 目前记录数量、nature、class 和组件数量，但组件至本系统 B-Rep/GLB 的实体身份尚未核实，不能定位。
- 文档所属按同一采集会话中的 CATDocument 对象登记；同名链接文档不会按显示名合并。标注集找不到原生所属文档时保留 unresolved，不默认挂到根文档。
- `caa_capture_v1` 的 PMI 通道通过现有 Reader、Revision 事务与 PostgreSQL JSONB 证据表发布；导入检查对象 ID、关联端点、声明文件是否存在、数量和已声明的 SHA-256。旧包未声明的可选通道可缺失，不能视为非空标注验收。API 分页/按 ID 查询标注，支持类型、标注集、视图/捕获 ID、读取状态、文本搜索；详情返回成员关系及映射状态。
- Feature Center 窄侧栏浏览标注与集合，右侧按类型显示原生字段、原文、层级、关系和来源。Viewer 只有可信当前版本渲染范围才高亮；未映射的 MBD 标注明确显示无法精确定位。已有几何识别对象的确认范围用主题色，候选/待复核选区用 Element Plus 警告黄色；颜色不改变后端分类。

## 八类逐项状态

| 类别 | 代码可读内容 | 真实非空 R21 样件 |
| --- | --- | --- |
| 尺寸 | 名义值、极限、线性子型原始枚举；仅线性值标 mm，角度/未知单位仍待核实 | `not_run` |
| 形位公差 | 语义/非语义接口类型、公差带值/形态、复合值与基准框文本的可得原始字段；完整修饰与几何引用未解码 | `not_run` |
| 粗糙度 | `GetField(1..9)` 原文与索引；九项含义未知 | `not_run` |
| 基准 | 简单基准/体系类型与可得标签 | `not_run` |
| 文本 | 原始多行文本；不执行 HTML | `not_run` |
| 旗标 | 旗标文本及可得外部 URL 原文 | `not_run` |
| NOA | 原生类型、文本及可得外部 URL 原文 | `not_run` |
| 视图/捕获 | 原生成员关系、可得视图平面；捕获相机仅记录存在状态 | `not_run` |

`M-D53` 未获客户编码定义，不解释成某个字符集。客户工艺 K 孔没有规则/规范样件，本轮不自动分类。功能定义集完整层级、标注三维布局、原生截图、形位公差框精确复原、标注到真实几何面的双向索引仍未完成；这些字段在 UI 中保持未映射/不支持，不以集合几何或整件高亮替代。当前 Web 浏览器打开的是纯 STEP 样件，不能充当 P5 非空标注视觉验收。

## 测试与恢复

- 原 P5 基线：本机 R21 x86 `mkmk` 编译、VS2008 核心测试、后端 74 项及前端 88 项通过。2026-10-04 修复轮：R21 x86 `mkmk` 已编译新增接口；后端目标测试 54 passed、1 skipped（未设置实时数据库开关），另以 `P5_LIVE_DB=1` 单独运行 PostgreSQL 事务/查询测试 1 passed。VS2008 核心测试及最终编译结果见本轮交付记录。手写测试包只证明入库/API，**不证明 CAA 原生读取**。
- 非空真实 FT&A/TPS 样件、八类设计值对照、装配重复实例属性、360/400/440px MBD 浏览器验收均为 `not_run`。TTRS 目标身份、功能定义/连接图形集成员、完整多段形位公差仍未核验；这些能力不能供 P6 声称原生已解析。没有把旧 P2/P3 样件或测试 JSON 算成这些验收。
- 旧采集包若没有新增 P5 字段，回填只保存原包实际内容；必须从 CATPart/CATProduct 重新只读采集才能获得新字段。已有包含 P5 通道的包可用现有原生证据回填命令；入库失败事务回滚，上一可用 Revision 证据保留。
