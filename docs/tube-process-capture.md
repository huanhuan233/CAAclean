# 导管工程信息采集

## 模块边界

`CaaEngineeringCapture::Extract` 封装 CATIA 接口查询、对象身份解析、公式输入输出、几何引用、中心线展开和失败隔离。调用方只提交当前采集包。关联 CATPart 的采集在文档句柄关闭前完成；输出继续使用 PropertyFact、FeatureDependency 和 SemanticFacet，保持原有数据库路径。

`AnalyzeTubePath` 是独立的 C++03 计算模块，不依赖 CATIA、数据库或 JSON。输入是毫米制实测直线/圆弧段，输出是经过完整校验的有序几何链。模块内部负责连通性、方向、圆弧恢复、长度交叉检查、切向连续性和空间转角；调用方不必执行多步校验协议。

2026-10-08 的 P7A 扩展把原始曲线段与连续几何组分开。`tube_geometry_v2` 额外保存定义坐标中的端点 A/B、每段累计弧长区间、起止切向、解析圆弧圆心/法向以及组到原始源 ID 的映射。`AnalyzeTubePath(..., reverse_direction=true)` 从另一端重新推导弯序与首尾直段；默认端点按零件定义坐标选择，装配摆放不改变这个顺序。`tube_object_status` 明确标为原生扫掠路径候选、空心截面未核验。连续弯曲组数用于 `tube_bend_count`，拆分圆弧不虚增物理弯数。

本机 VS2008 独立核心测试通过。设置现有 R21 安装的 `CAA_RADE_ROOT` 和 `CAA_PREREQ_ROOT` 后，R21 x86 `mkmk` 编译通过。对 SHA-256 为 `A10E3CD5151CA37B0F19C4480F02C5FCFA8A53F28CE210187C57AD9627C357D3` 的历史 CATPart 重新采集，`tube_geometry_v2` 与 13 个连续几何组实际生成，`test_tube_bundle.py` 的 3 项实件回归通过。新包位于忽略目录 `.runtime/tube-p7a-r21-20261008`。

P7B 的 R21 草图采集增加解析圆心，真实扫掠输入草图里的两条完整同心圆可得外径 6 mm、内径 5 mm、名义壁厚 0.5 mm。这是**原生设计截面**，并非已测得实体全程壁厚。独立 FreeCAD 受限核验仅确认闭合、有效、两张同轴完整圆柱壁和两张环形端面的直管，能量出解析外径、内径、壁厚、中心直段和两个平口；实心杆和钻孔方块是反例。圆环弯管、斜口、扩缩口及自由曲面管暂记不支持，不把它们转写为平口直管。

新增及本次修改的 C++ 函数均有中文注释。没有修改、更新或保存原始 CATPart。

## 新增数据

- `formula_expression`：`CATICkeRelationExp.Body(0)` 的已保存公式，不触发求值；保存有序输入、输出参数引用及更新状态。
- 对象值参数不伪装成树节点：记录 `non_spec_parameter`、参数名称和显示值，再通过 `CATICkeParm.Value().AsObject()` 保存 `_value_object` 的实际对象依赖。本样件面积、体积公式的 `Double` 输入均由此追溯到真实对象。
- 直线端点、圆弧控制点/支撑、三点平面、扫掠截面及中心线、CenterCurve 包装对象、Join 成员的真实依赖。
- `centerline_measurement`：原生测量端点、中点、长度、半径（毫米）。R21 的接口查询成功不代表实际曲线类型，必须使用 `GetShapeName` 分类。
- `tube_bending_geometry`：按连通性排序的几何链、直段长度、弯角、弯前直段、相邻弯曲平面转角、尾直段和总展开长度；保留对象 ID、单位和方向约定，来源标记为 `derived_geometry`。

首弯无参考弯曲平面，`rotation_deg` 为 `null`，不能当作实测零度。遍历起点为坐标字典序较小的端点；转角按前进切线右手方向计算。该方向是确定性几何约定，不是生产装夹方向。

## 失败与兼容约束

空链、闭合链、分叉、断链、重复成员、不支持的曲线、非有限值、退化段、测量矛盾和非切向连接均拒绝产生弯曲表，保存明确状态。引用未被采集时保留 `not_captured`，不制造对象 ID 或悬空外键。原有语义载荷保留，结果体统计仅统计 `has_resultout_body`，不把工程依赖误算为结果体。

不根据文件名、参数名 D 或 Rib 类型认定所有扫掠都是空心导管。原生工艺规范、材料、坐标和参数仍保留其原有事实；几何计算不替代原始参数。机床进给、回弹、夹持、模具和工艺补偿未提供，不能把此表直接称为机床加工程序。

## P7C 导管结果与安装间隙（2026-10-08）

`POST /api/component-builds/{build_id}/tube/analyze` 以当前 Revision 的可信 STEP 世界坐标 Solid 映射为输入，一次 FreeCAD 作业内加载指定导管与 1–31 个目标实体。导管必须是单个可核验的直空心管；任意装配实例变换或缺失映射会返回具体错误，不混用零件定义坐标。圆柱外壁和两个环形端面参加外表面最短距离计算，返回见证点、中心线站位、相交状态和数值容差状态。没有用户给定安装阈值时不判定合格/不合格。弯管外壁、斜端、扩口及复杂接头仍为 `unsupported`，不能用这套直管结果代替。

结果按 `tube_run`、`tube_records`、`tube_clearances` 发布到既有 `CadNativeEvidence`，绑定 Revision、快照、几何资产 SHA、算法版本和容差；失败不替换上一可用结果。`GET /tube/paths/step` 和 `GET /tube/clearances` 分页读取发布结果并报告快照是否仍匹配。`GET /tube/paths/native` 从已入库的原生 `tube_bending_geometry` 属性读取，不解析采集 JSONL。原生扫掠路径与 STEP 几何测量保留不同来源；历史包只能显示当时已有的路径字段，新增 R21 圆心和截面参数需要重新采集并入库，STEP 安装间隙只需对已有可信快照补算。

左侧“特征→导管”可浏览原生路径、STEP 几何导管和安装间隙；选择中心线时叠加真实线段，解析圆弧只在圆心、平面法向和端点完整时绘制。右侧显示路径、截面或距离证据；无法核验的管体不冒充精确实体选区。自动化：P7C FreeCAD/数据库 2 项、P7B 相关 4 项通过；旧 CATPart 包的真实浏览器路径列表和右侧详情已验证。旧包没有新截面字段，STEP 实体快照也不可用，因此该实件上的几何导管与安装间隙浏览器验收为 `not_run`，未声称实件已核验安装距离。
