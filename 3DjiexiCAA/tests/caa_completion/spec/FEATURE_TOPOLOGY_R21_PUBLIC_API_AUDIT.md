# R21 Feature-Topology Public API Audit

Baseline: remote `main` commit `3d99007`, CATIA V5R21 32-bit build.

## Investigated Header Paths

`D:\CATIA\MecModInterfaces\PublicInterfaces\CATIShapeFeatureBody.h`

- Framework/library: `MecModInterfaces` / linked through `MecModItfCPP`.
- IID: `IID_CATIShapeFeatureBody`; use `QueryInterface(IID_CATIShapeFeatureBody, ...)`.
- Key signatures:
  - `virtual CATISpecObject_var GetResultOUT() = 0;`
  - `virtual CATListValCATBaseUnknown_var* GetBodyOUT(CATClassId iInterfaceName) = 0;`
  - `virtual CATListValCATBaseUnknown_var* GetShape(CATClassId iInterfaceName) = 0;`
  - `virtual CATListValCATBaseUnknown_var* GetBodyIN(CATClassId iInterfaceName) = 0;`
  - `virtual CATIShapeFeatureBody_var GetNextShape() = 0;`
  - `virtual CATIShapeFeatureBody_var GetPreviousShape() = 0;`
- Ownership: list pointers returned by `GetBodyOUT/GetShape/GetBodyIN` are caller-owned and must be released/deleted according to the CATIA list/var conventions already used in the parser.
- Compile result: current R21 x86 `mkmk` build succeeds with this interface included and used.
- Minimal run result: Hole, Fillet, and Boolean fixtures emit per-feature ResultOUT cells, but the same final `CATCell*` appears in multiple previous feature ResultOUT bodies.
- Proves: a feature exposes a runtime ResultOUT/BodyOUT topology and procedural predecessor/successor ordering.
- Does not prove: that a matching final face was generated by that feature, not inherited from cumulative prior state, or persistent after close/reopen.

`D:\CATIA\MecModInterfaces\PublicInterfaces\CATIPrtPart.h`

- Framework/library: `MecModInterfaces` / `MecModItfCPP`.
- IID: `IID_CATIPrtPart`; use `QueryInterface(IID_CATIPrtPart, ...)`.
- Key signatures:
  - `virtual CATBody_var GetSolid() = 0;`
  - `virtual CATISpecObject_var GetFeatureSolid() = 0;`
  - `virtual CATISpecObject_var GetCurrentFeature() = 0;`
- Ownership: returned `_var` smart variables manage interface references.
- Compile result: current R21 x86 `mkmk` build succeeds with final solid extraction.
- Minimal run result: final `CATBody` cell enumeration is available for Part Design fixtures.
- Proves: current final main-body topology in this CATIA session.
- Does not prove: which feature generated, modified, consumed, split, or merged each final cell.

`D:\CATIA\GMModelInterfaces\PublicInterfaces\CATCell.h` and `D:\CATIA\GMModelInterfaces\PublicInterfaces\CATBody.h`

- Framework/library: `GMModelInterfaces`.
- Key signatures/notes:
  - `CATCell` exposes topology dimension, geometry, adjacency, boundary and neighbour traversal.
  - `CATCell::IsCandidateForReporting(CATBody*)` and several `CATBody` propagation methods are marked `@nodoc`.
  - `CATBody::CellNeighbours(..., const short iVersionGenericNaming = 0)` contains a generic-naming parameter but returns neighbourhood topology, not feature history.
- Compile result: current R21 x86 `mkmk` build succeeds with CATBody/CATCell enumeration.
- Minimal run result: final and ResultOUT bodies can be enumerated, measured and compared in one process.
- Proves: runtime topology, geometry and adjacency.
- Does not prove: semantic history relation or persistent identity.

`D:\CATIA\MecModInterfaces\PublicGenerated\intel_a\CATIAPart.h`

- Framework/library: Automation generated MecMod public IDL.
- IID: `IID_CATIAPart`.
- Key signatures:
  - `CreateReferenceFromObject(CATIABase* iObject, CATIAReference*& oRef)`
  - `CreateReferenceFromGeometry(CATIABase* iObject, CATIAReference*& oRef)`
  - `CreateReferenceFromBRepName(const CATBSTR& iLabel, CATIABase* iObjectContext, CATIAReference*& oRef)`
- Ownership: returned `CATIAReference*` is a COM interface and must be released by the caller.
- Compile result: header is available in the R21 32-bit public generated tree; no parser integration was added in this round.
- Proves: Automation can create/select references from known objects or known BRep labels.
- Does not prove: a generated/modified/consumed/split/merged relation unless the BRep label itself came from a verified public history API. No such public source was found in the audited paths.

## Conclusion

No audited R21 PublicInterfaces/PublicGenerated path proves full Feature-Topology history semantics for `generated`, `modified`, `consumed`, `split`, or `merged`.

The parser therefore keeps ResultOUT/final solid pointer identity as runtime evidence only:

```text
mapping_status=runtime_matched
mapping_method=catia_resultout_final_cell_pointer_identity
authority=runtime_cell_identity
relation_kind=survives_to_final
persistent_reference=""
```

Authoritative Feature-Topology history mapping remains:

```text
BLOCKED_PUBLIC_API_R21
```
